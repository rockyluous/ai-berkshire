## 五、判断

1. **流程决定错误率，模型决定洞察深度**——这是三轮最清楚的结论。v1→v2 冲突 3→0、手工修正 7→0，模型没换；v2→v3 数据层没有更好（同一份底稿），但分析层出现了 v2 完全没有的 17 项发现，且抓出 v2 一个 20 倍计算错。
2. **Opus 的边际收益集中在两个角色**：财务（反向折现、EV/EBIT、SOTP 压力测试、分部漏损）与芒格（份额增量来源、平台化、循环性）。段永平与李录的差异更多在"证伪能力"而非"事实量"。
3. **代价**：壁钟时间 3 倍（23 分钟 vs 8 分钟），token 与 v2 相当（v2 被李录子任务拉高）。对 A 级信息充裕公司，Opus 值得；对 C 级信息稀缺公司，模型差异预计缩小，流程更重要。
4. **v4（Fable）的边际收益在"证据分辨率"而非"结论"**：结论与买点方向和 v3 一致，但把关键判断从定性推到了可分解、可证伪的量级（付费点击×CPC、AIO 按意图覆盖率、承诺轨迹、VWAP 偏差）。三个 Agent 未派子任务、一个派了 2 个（在上限内），成本比 v3 高 ≈ 48%，壁钟反而短（18 分钟 vs 23 分钟）。
5. **v4 同时暴露了新纪律的两个副作用**：① 两个 Agent 把"在 10-Q 里见过"写成"一手证实"——抽查表制度**提高了核实的量，也提高了对核实质量的要求**，team-lead 必须对"一手证实"抽查中的抽查；② 双算表指标命名不统一（"核心 EPS（口径 A）" vs "核心 EPS（全额剔除）"），工具已改为按基名分组、口径不同单独标注。
6. **两处未决**，四轮都没解决：Cloud 收入中关联方（Anthropic）占比；AI Capex 合同承诺 $8,110 亿是否有 10-Q 原文。这两项是下一轮的第一优先级。第三项新增：**MD&A 合同义务表原文**（$8,110 亿口径）——SEC 对未声明工具的封锁使全文取不到，需设 `SEC_USER_AGENT` 或人工读。
