## 核心论文（未买入版：什么条件成立才买）

```
我暂不在 $497 买入 Microsoft，因为：
1. 这门生意有两部分——Productivity & Business Processes 是 ★5 级收租生意
   （利润率 59.9%、增量利润率 73.5%），我理解它；Azure/AI 增量的回报路径我看不清。
2. 它的护城河是企业转换成本与企业协议分发（★5），但模型层是空的（★2）——
   持股 25% 的 OpenAI 企业 API 份额已从 50% 跌到 27%，独家条款也已退出。
3. 管理层程序化回购十年无择时失误、LinkedIn 成功，但 Activision 为负，
   CEO 绩效股 100% 挂收入、0% 挂回报率——与 $1,750 亿 Capex 时代错配。
4. 当前价格是公允价：核心 PE 28.8–29.6x 处自身十年 36% 分位，对 FY27 一致预期
   中位折价 7%——不贵，但也没有边际。
5. 我不买的原因是回报路径不可证伪：净利润五年 +84% 而 FCF +3%；
   来自 OpenAI 的收入占 7.3%、RPO 占三成以上，其履约能力无法核实。
```

**买入条件**：股价回到 $430 以下（FY27 EPS × 22x），或 Q1 FY27 财报同时满足：新口径 Azure ≥44%、Copilot 席位继续披露且 ≥4,000 万、FY27 FCF 指引 ≥ $400 亿。
