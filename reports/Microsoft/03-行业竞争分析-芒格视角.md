## 二、行业规模与增长

### 2.1 云基础设施（IaaS + PaaS + 托管私有云）

Synergy Research Group 五个季度时间序列（一手，官网新闻稿）：

| 季度 | 市场规模（亿美元） | 同比 | 说明 |
|---|---|---|---|
| 2025Q2 | 988 | +24–25% | 新闻稿 2025-07-31；TTM 3,660 亿 |
| 2025Q3 | 1,069 | +30% | 新闻稿 2025-11-19；TTM 3,900 亿 |
| 2025Q4 | 1,191 | +30% | 新闻稿 2026-02-05；2025 全年 4,190 亿 |
| 2026Q1 | 1,286 | +35% | 新闻稿 2026-04-29；TTM 4,550 亿 |
| 2026Q2 | **1,434** | **+43%** | 新闻稿 2026-07-30；TTM 5,000 亿；"八年来最高增速"；GenAI 专属云服务 +165%，公有 IaaS+PaaS +47% |

- 事实：增速连续九个季度加速（Synergy 原话），从 2025Q2 的 25% 升至 2026Q2 的 43%。
- 反面论据：Synergy 同时列出 OpenAI、Anthropic 作为"增长最快的二线云提供商"（2026Q1、Q2 新闻稿），说明**模型公司自身已被统计为云供应商**，市场增速里含有模型层向基础设施层的"自我循环"部分；且 Synergy 2025-07 曾预测"未来五年平均增速保持在 20% 以上"，43% 显著高于机构自身的长期预期，属周期高点还是新常态，**数据不足以判断**。

行业增速：★5（八年最高）。

### 2.2 企业软件 / 生产力套件

- 全球企业软件总盘的一手数据未取得（Gartner 官网 403，二手转述给出 2026 年公有云终端用户支出 8,500 亿美元、+21.3%，**未核一手**），按 CLAUDE.md 原则记为"数据不足"。
- 可用一手代理指标（微软 2026-09-02 重述文件）：Microsoft 365 cloud（新口径，含商用+消费+GitHub 云+Security Copilot）FY26 收入 **1,003.0 亿美元**（FY25 846.1 亿，+18.5%）；Microsoft 365 商用云（旧口径）FY26 +17%，10-K 原文称"每用户收入增长由 Microsoft 365 Copilot 与 E5 驱动"，商用席位 +6%（"由中小企业与一线员工产品驱动"）。
- Google 侧：Alphabet 不单独披露 Workspace 收入（并入 Google Cloud）。2026Q2 电话会（blog.google 一手）仅称 Workspace"席位数与每席位收入均增长，收入双位数增长"，无绝对值。

行业增速：★3（微软自身口径高个位数席位 + 低双位数 ARPU，总盘增速数据不足）。

### 2.3 AI 基础设施与模型 API

- 需求侧：Menlo Ventures（一手）——企业生成式 AI 支出 2024 年 115 亿美元 → 2025 年 **370 亿美元**（+222%）。
- 供给侧收入运行率（二手，Bloomberg 首发）：OpenAI 2025 年末 200 亿 → 2026-07 **400 亿**美元；Anthropic 2025 年末 90 亿 → 2026-04 300 亿（Anthropic 官网自述，一手）→ 2026-05 470 亿 → 2026-07 末 **650 亿**美元。
- 算力侧：Nvidia Q2 FY27（季度止 2026-07-26，SEC 原文一手）数据中心收入 **890 亿美元**，同比 +117%，毛利率 75.0%；下季指引 1,080 亿。
- 反面论据：运行率是"最近一个月 × 12"，不是审计收入；Anthropic 从 300 亿到 650 亿只用了四个月，这种斜率在软件史上没有先例，既可能是真实需求，也可能含有大量前置合同的确认时点效应，**无法用公开数据区分**。

行业增速：★5（但**可持续性数据不足**）。

### 2.4 游戏

- Newzoo 2026 年全球游戏市场 **2,139 亿美元**，+6.1%；主机 469 亿、PC 459 亿、移动 1,211 亿（二手转述，newzoo.com 拒绝抓取）。
- 微软 XBOX（重述文件一手）FY26 收入 **217.9 亿美元**，同比 −7%；10-K 原文：内容与服务 −5%，**硬件 −29%**；Q4 FY26 内容与服务 −10%（新闻稿一手，管理层归因于 Game Pass 调价）；Q1 FY27 指引：内容与服务"中个位数下降"，硬件继续下降。
- 自算：217.9 / 2,139 ≈ **10.2%**（财年 vs 日历年错位，仅作量级参考）。

行业增速：★2；微软在该行业方向：★1（连续下滑）。

**B. 本报告自算口径（分子=公司报告分部收入，分母=Synergy 市场规模；口径混合，仅作方向性交叉验证）**

自算结论与机构口径方向一致：**AWS −1.9 pt，Azure 持平（−0.5 pt），GCP +3.5 pt**（Google 数字偏高是因分子含 Workspace，Synergy 把它剔了）。

**C. 增量来自谁（2026Q2 vs 2025Q2，自算）**

市场增量 1,434 − 988 = **446 亿美元**：
- AWS：422 − 309 = 113 亿 → **25.3%**
- Azure（重述口径）：294.2 − 207.1 = 87 亿 → **19.5%**
- Google Cloud：247.7 − 136.2 = 111.5 亿 → **25.0%**
- 三家合计 69.9%；**其余 30.1% 来自 Oracle、CoreWeave 等 neocloud、以及被 Synergy 计为云供应商的 OpenAI/Anthropic**。

关键事实：Azure 以 +42%（重述口径 Q4 FY26）的增速，在绝对增量上**低于 AWS（+37%）与 GCP（+82%）**，因为 Azure 基数（季度 294 亿）介于两者之间而增速不是最高。"Azure +43%"的绝对基数：FY26 重述口径 Azure 收入 **1,019.4 亿美元**（FY25 726.1 亿，+40.4%），新闻稿原话"Azure 收入首次突破 1,000 亿美元"。

反面论据：Synergy 口径下 Microsoft 份额从 2025Q4/2026Q1 的 21% 回落到 2026Q2 的 20%，与自算的 20.2%→20.5% 方向相反，差异在四舍五入区间内，**不能据此判断份额转折**。

### 3.2 生产力套件：M365 vs Google Workspace

- 一手可得的只有微软单方数据：M365 Copilot 付费席位 **1,500 万（2026-01）→ 2,000 万（2026-04）→ 3,000 万+（2026-07，新闻稿一手）**；M365 商用付费席位"超过 4.5 亿"（2026-01 电话会，二手转述）。自算渗透率 30 / 450 ≈ **6.7%**；列价上限 ARR 3,000 万 × $30 × 12 ≈ 108 亿美元（**估计，实际折扣后更低**）。
- Google 侧一手：2026Q2 电话会"财富 100 强中近 90% 在使用 Gemini Enterprise"（blog.google）；Workspace 收入不单独披露。
- 份额时间序列：**数据不足**。可得的二手引用（域名计数口径 Google 50% / 微软 45%；企业段微软 58–77%）口径互相矛盾，本报告不采用。Gartner 早年结论"Google 每年从微软手中拿走 1–2 个百分点"（Gartner 文档标题，未读原文）仅作提示。

### 3.3 模型 / API 层：OpenAI vs Anthropic vs Google（微软的间接位置）

Menlo Ventures 企业 LLM API 支出份额（一手，问卷口径）：

| 年份 | OpenAI | Anthropic | Google | Meta | 其他 | 合计（自复算） |
|---|---|---|---|---|---|---|
| 2023 | 50% | 12% | 7% | — | 31% | 100% ✓ |
| 2024 | ~38% | 24% | ~14% | — | ~24% | 100% ✓ |
| 2025 | **27%** | **40%** | 21% | ~5% | ~7% | 100% ✓ |

编码细分（Menlo 同报告）：Anthropic 54%（六个月前 42%），OpenAI 21%。

**微软的间接位置**：微软自身在这张表上**没有份额**。它的模型层暴露 = 持有 OpenAI 约 25%（10-K FY26 原文"approximate 25% interest on an as-converted basis"）+ 对 Anthropic 最多 50 亿美元投资（Anthropic 官方页面）+ 自研 MAI 模型（2026-04-02 发布三款，TechCrunch；Build 2026 又发七款，仅见二手博客，**未核**）。OpenAI 份额从 50% 跌到 27%，意味着微软持股对象**在企业 API 市场正在失势**；而份额上升者 Anthropic 的算力承诺中，Azure 300 亿 vs AWS >1,000 亿 vs Google（媒体称 2,000 亿，未确认）——若媒体数字成立，Azure 只占约 9%（自算 30/(30+100+200)）。

反面论据：Menlo 样本是 495 名美国企业决策者的问卷，"份额"是受访者报告的支出比例，不是审计收入；OpenAI 收入运行率仍在翻倍（200 亿→400 亿），份额下降是分母膨胀更快，不是绝对萎缩。

### 3.4 企业 AI 采用：Copilot vs 其他

- LayerX 遥测（单一低级别来源，方法未披露）：企业用户使用占比 ChatGPT 36.2% / M365 Copilot 29.6% / Gemini 13.0% / Claude 11.9%；对话量占比 ChatGPT 55.1% / Copilot 23.6% / Gemini 10.4% / Claude 6.5%。**Copilot 用户占比接近 ChatGPT，但活跃度（对话/用户）只有 ChatGPT 的一半左右**。
- 一手对照：微软 10-K 原文承认 M365 商用云"每用户收入增长由 Copilot 与 E5 驱动"，即 Copilot 已在财报兑现为 ARPU；但席位增长只有 6%，且来自中小企业与一线员工，**大企业席位增长未被单独披露**。
- Salesforce（一手新闻稿 2026-08-26）：Agentforce ARR >15 亿美元（+240%）；ServiceNow（二手转述）：AI ACV 突破 10 亿。两者合计约 25 亿，与 Copilot 列价 ARR 上限 108 亿相比量级悬殊，但增速远高。

## 四、核心竞争者逐个评估

> "任何能赚取巨额利润的地方，都会引来竞争。"——芒格

### 4.1 Amazon / AWS —— 威胁 ★4
- 一手（8-K Ex.99.1 2026-07-30、10-Q）：2026Q2 AWS 收入 **422 亿美元**（+37%，"18 个季度以来最快"），经营利润 166 亿（Q2 2025 为 102 亿），经营利润率自算 39.3%；长期合同未确认收入约 **4,960 亿美元**，加权剩余期限 6.4 年；Q2 净利润含来自 Anthropic 投资的 534 亿税前收益；TTM 资本开支 1,730 亿。
- 对微软的具体威胁：(a) 2026-02-27 与 OpenAI 签 1,000 亿/8 年扩展（原 380 亿），并成为 OpenAI 企业平台 Frontier 的**独家第三方云分销商**（Amazon 新闻中心一手）；(b) Anthropic 承诺十年 >1,000 亿、最多 5GW Trainium（Anthropic 一手）。
- 反面：AWS 份额五个季度从 30% 降到 28%；37% 增速仍低于 Azure。

### 4.2 Google / Alphabet —— 威胁 ★5
- 一手（8-K Ex.99.1 2026-07-22、10-Q）：Google Cloud 2026Q2 收入 **247.7 亿**（Q2 2025 136.2 亿，+82%），经营利润 88.1 亿（去年 28.3 亿），利润率自算 35.6%；云积压 **5,139 亿美元**，"略过半在 24 个月内确认"。
- 结构性优势：唯一同时拥有自研芯片（TPU）、前沿模型（Gemini）、云和应用（Workspace）的对手；Nvidia 新闻稿列出 Vera Rubin 首批部署伙伴含 Google Cloud，说明其 GPU 与 TPU 双轨。
- 对微软的具体威胁：增量份额 25%（自算）≥ AWS，>Azure；Gemini Enterprise 覆盖近 90% 财富 100 强（blog.google 一手）；媒体称 Anthropic 五年 2,000 亿承诺占其积压 >40%（The Information，**双方均未确认**）。
- 反面：GCP 绝对份额 15%，仍是第三；积压高度集中于单一客户（与微软–OpenAI 同构）。

### 4.3 Anthropic —— 威胁 ★3（伙伴属性 > 竞争属性）
- 一手：2025-11-18 承诺 300 亿 Azure + 最多 1GW，微软投资最多 50 亿、Nvidia 最多 100 亿；Claude 进入 Microsoft Foundry 与 Copilot 家族；2026-04-06 自述运行率 300 亿。
- 威胁面：企业 API 份额 40%、编码 54%（Menlo），直接压缩 OpenAI（微软持股）在企业市场的空间；其算力主要在 AWS/Google，Azure 只是第三家。
- 收益面：微软 Q4 FY26 已确认 32 亿美元 Anthropic 投资收益（新闻稿一手）；Claude 在 Copilot 中可选，降低了微软对单一模型的依赖。

### 4.4 OpenAI —— 威胁 ★4（最大客户 = 最大结构性风险源）
- 一手（10-K FY26 关联方附注）：FY26 微软确认来自 OpenAI 的商业安排收入（含收入分成）**241 亿美元**，占总收入 7.3%、占重述口径 Azure 收入 **23.7%**（自算）；应收 60 亿；资金承诺 130 亿已出资 119 亿；持股约 25%（3 月 10-Q 为约 27%，**再度稀释**）。
- 一手（Microsoft 博客 2025-10-28）：OpenAI 承诺**增量采购 2,500 亿美元 Azure**；微软失去算力**优先购买权**；"API 产品在 Azure 独家，非 API 产品可在任何云"。
- 一手（Microsoft 博客 2026-04-27）：IP 许可改为**非独家**（至 2032）；"OpenAI 现在可以在任何云提供商上向客户提供其全部产品"；微软不再向 OpenAI 支付收入分成；OpenAI 向微软的分成"按相同比例延续至 2030，但设总额上限"（上限金额官方未披露；CNBC 等报道为 380 亿，VentureBeat 明确称"未披露"，**存疑**）。
- 竞争面：ChatGPT Enterprise 直接对位 M365 Copilot（LayerX 用户占比 36% vs 30%）；Codex 对位 GitHub Copilot；Frontier 平台的独家分销给了 AWS 而不是 Azure。

### 4.5 Oracle —— 对 Azure 核心业务 ★2 / 对 AI 训练算力 ★3
- 一手（Q1 FY27 8-K Ex.99.1，2026-09-10）：OCI 收入 **74 亿**（+121%），总收入 193 亿；RPO **6,640 亿**（同比 +2,090 亿）；单季交付 850MW；Q1 自由现金流 **−50 亿**；季内通过 ATM **增发 200 亿美元普通股**。

- 反面：OCI 季度收入是 Azure 的 1/4，且靠负现金流和增发股票扩张；对微软的威胁是分流 OpenAI 训练负载，而非争夺企业客户。

### 4.6 Salesforce / ServiceNow —— 威胁 ★2

## 五、OpenAI 关系的产业链含义

> "把激励机制给我看，我就能告诉你结果。"——芒格

### 5.1 四层各自有没有经济租金

| 层 | 微软的位置 | 有无租金 | 证据 |
|---|---|---|---|
| 算力（芯片） | 买方；Maia 自用 | **无**（租金归 Nvidia：毛利率 75%，一手） | Nvidia Q2 FY27 数据中心收入 890 亿 |
| 基础设施（Azure） | 全球第二，份额 20–21% 持平 | **有但在被稀释**：Microsoft Cloud 毛利率 FY24→FY25→FY26 为 →69%→**66%**（10-K 原文）；Intelligent Cloud 经营利润率 FY25 42.0% → FY26 41.3%（自算） | 2026Q2 增量份额 19.5%，低于 AWS 与 GCP |
| 模型 | 无自有前沿模型份额；持股 OpenAI ~25% | **租金只有间接股权与分成**；分成已设上限、许可改非独家 | Menlo：OpenAI 份额 50%→27% |
| 应用 / 分发 | M365、GitHub、Windows | **有**：Copilot 3,000 万席位，ARPU 已兑现 | 渗透 6.7%，活跃度低于 ChatGPT（LayerX） |

结论：微软的租金在两端（分发、基础设施），**中间的模型层是空的**，而且基础设施层的租金正被资本开支和竞争摊薄。

### 5.2 模型层依赖 OpenAI 的结构性风险（量化）

- 收入端：OpenAI 贡献 FY26 收入 241 亿（一手），占 Azure 约 24%。
- 积压端：商业 RPO 时间序列（10-Q/10-K 一手）：2025-12 6,250 亿（+110%）→ 2026-03 6,270 亿（+99%）→ 2026-06 **6,780 亿（+84%）**；加权久期 2.5 → 2.3 年；12 个月内确认比例 25% → 30%。电话会：剔除 OpenAI 仅 **+25%**（转录，非官方）。
- 自算 OpenAI 在 RPO 中的占比：去年同期 RPO = 678/1.84 ≈ 3,685 亿。若去年 OpenAI 占比≈0，则今年 OpenAI RPO ≈ 678 − 1.25×368.5 ≈ **2,174 亿（32%）**；若去年已占 20%，则 ≈ 3,095 亿（**46%**）。**区间 32–46%**，与媒体分别引用的"32%"和"45%"两个数字对应两种假设——微软**未披露**去年基数，所以这个区间本身就是信息：单一关联方客户占积压三到四成。
- 会计端：FY26 其他收益中 OpenAI 相关净收益 **65 亿美元**（税前，主要为重组稀释收益，10-K 原文），FY25 为 −48 亿；这意味着微软的 GAAP 利润对 OpenAI 的估值事件高度敏感，而 OpenAI 本身是否盈利**数据不足**（FY25 微软按 HLBV 法承担 OpenAI 相关净损失 36.2 亿，新闻稿一手）。

### 5.3 OpenAI 多云化对 Azure 的影响

OpenAI 已披露/报道的算力合同（Azure 之外）：

| 对手方 | 金额 | 期限 | 来源等级 |
|---|---|---|---|
| Microsoft Azure | 增量 2,500 亿 | 约至 2030 | 一手（微软博客 2025-10-28） |
| AWS | 380 亿（2025-11）+ **1,000 亿 / 8 年**（2026-02-27）；约 2GW Trainium | 8 年 | 一手（Amazon 新闻中心） |
| Oracle | 3,000 亿 / 5 年，2027 年起，约 4.5GW | 5 年 | 二手（WSJ 首发，Oracle 未点名） |
| CoreWeave | 合计最多 224 亿 | 至 2029 | 二手（CoreWeave 新闻稿经转述） |
| Google Cloud | 金额未披露 | — | 二手（Reuters 2025-06） |

影响判断：
- 事实一：OpenAI 对 Azure 的 2,500 亿承诺**仍在**（2026-04 修订未撤销，微软博客未提及变更）。
- 事实二：Azure 在 OpenAI 已披露承诺中的份额自算 = 250 / (250+138+300+22.4) ≈ **35%**（不含 Google，媒体金额口径混合，仅作量级）。
- 事实三：微软失去了两样东西——算力优先购买权（2025-10）和产品独家分发权（2026-04）；保留了"先在 Azure 上线"的软约束（原文附带"除非微软不能且选择不支持"）。
- 反面论据：多云化让微软**不必为 OpenAI 全部训练需求背资本开支**——FY27 Capex 指引约 1,750 亿已占一致预期收入的 44.7%（自算），若还要独家供给 OpenAI，负担更重。Amy Hood 电话会原话"客户需求持续超过可用产能"，说明现在的约束是供给而非需求，OpenAI 分流短期对 Azure 收入无损。

## 八、芒格式逆向：五条"微软会输"的路径

> "我只想知道我会死在哪里，然后我永远不去那儿。"——芒格

### 路径 1：模型层空心化——OpenAI 去独家、Anthropic 在别家，Azure 沦为"可替换的管道"
- 证据强度：**高**
- 已在财报兑现：OpenAI 占 Azure 收入约 24%、占 RPO 32–46%（10-K 一手 + 自算）；剔除 OpenAI 后 RPO 增速从 84% 降到 25%、bookings 18%（电话会）。
- 行为层：2026-04-27 许可非独家、任何云可售（一手）；Frontier 独家分销给 AWS（一手）；Anthropic 算力主体在 AWS/Google（一手）。
- 反面：微软保留至 2032 的 IP 许可和 2,500 亿 Azure 承诺；MAI 模型已进 Foundry（TechCrunch）。

### 路径 2：资本开支吞噬自由现金流，靠会计估计变更撑利润
- 证据强度：**高**
- 已在财报兑现：Capex/营收 FY25 22.9% → FY26 **34.9%** → Q4 FY26 39.8%（自算）；FCF 三年 741→716→670 亿（底稿）而净利润 881→1,018→1,338 亿；FY27 Capex 指引约 1,750 亿 ≈ 一致预期收入的 44.7%。
- 行为层：折旧年限 15→25 年自 FY27 起（电话会转录；**FY26 10-K 固定资产附注仍为"建筑物 5–15 年"，变更尚未进入任何 SEC 文件**）。
- 反面：OCF FY26 1,829 亿仍覆盖 Capex；Amy Hood 称需求超过供给，产能利用率不是问题；Oracle 的负 FCF + 增发说明微软的资产负债表相对健康。

### 路径 3：Google 垂直整合（TPU+Gemini+Cloud）以成本优势持续拿走增量份额
- 证据强度：**中**
- 已在财报兑现：GCP +82% vs Azure +42%；2026Q2 增量份额 GCP 25.0% > Azure 19.5%（自算）；Synergy 份额 GCP 13%→15%，Azure 20%→20%。
- 行为层：Anthropic 多 GW TPU（一手）与媒体报道的 2,000 亿承诺（未确认）；Gemini Enterprise 覆盖近 90% 财富 100 强。
- 反面：GCP 经营利润率 35.6% 仍低于 IC 的 40.6%；绝对份额差 5 个百分点；Google 积压同样高度依赖单一客户。

### 路径 4：企业 AI 入口被 ChatGPT Enterprise / Claude 绕过，Copilot 只是"套件附件"
- 证据强度：**中**
- 行为层：LayerX 遥测 ChatGPT 对话占比 55% vs Copilot 24%（单一低级别来源）；Menlo 编码份额 Anthropic 54%（GitHub Copilot 所在赛道）。
- 财报层**未兑现**：M365 商用云 +17%，10-K 明言 ARPU 由 Copilot 驱动；Copilot 席位半年翻倍（1,500 万→3,000 万）。
- 反面：渗透率仅 6.7%，既是风险也是空间；4.5 亿席位的分发优势短期无人能复制。

### 路径 5：监管拆捆绑——CMA SMS 指定 + 欧盟 Teams 先例 + FTC 许可调查
- 证据强度：**低–中**
- 行为层已兑现：Teams 拆分 7–10 年承诺（2025-09）；CMA 认定微软许可损害 AWS/Google 竞争力（2025-07，一手）；SMS 调查进行中，2027-02 决定。
- 财报层**未兑现**：无罚款、无收入影响披露；Server products FY26 +1%（10-K：多云环境许可购买增加），反而说明许可条款仍在创收。
- 反面：CMA 已放过 AWS，只针对微软；若被指定 SMS，行为要求可能直接削弱"用 Windows Server/SQL Server 许可差价把客户留在 Azure"这一护城河。

## 九、本维度总体结论

**行业地位综合：★4**

数据显示的三件事：
1. 微软处在八年来增速最快的云市场里，份额**持平**（20–21%），增量贡献（19.5%）**低于** AWS 和 GCP——这是"跟上了市场、没有跑赢市场"。
2. 微软在产业链两端有租金（应用层 57.9% 分部利润率、基础设施层 40.6%），**中间的模型层没有租金**，且模型层的持股对象 OpenAI 在企业 API 市场份额从 50% 跌到 27%，同时把独家分发权给了 AWS。
3. 微软最大的客户是它的关联方：OpenAI 贡献约 24% 的 Azure 收入和 32–46% 的积压。这不是"AI 竞争激烈"这种废话，而是一个可计算的集中度数字，同构于 Google–Anthropic。

反面论据（芒格会让对方律师先说话）：Azure 1,019 亿的绝对规模、4.5 亿 M365 席位的分发、66% 云毛利率下仍 41% 的分部利润率、以及 FY27 Q1 Azure 44–45% 的指引，都说明护城河在当下**没有被突破**；五条败因中只有两条在财报层兑现，而这两条（关联方集中、Capex 挤压现金流）恰恰是**微软自己选择的**——它用资产负债表换取了 AI 时代的入场券，代价是把命运的三分之一交给了一家自己不控制的公司。
