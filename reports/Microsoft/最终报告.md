## 1. 一句话结论

微软是一门"存量极好、增量存疑"的生意：Productivity & Business Processes 利润率 59.9%、增量利润率 73.5%，是全球最好的收租生意之一；但增量押在 Azure/AI 上，而 **FY26 净利润五年 +84%、自由现金流只 +3%**，FY27 Capex ≈ $1,750 亿（一致预期收入的 44.7%）、未启动租赁 $3,291 亿一年翻 3.5 倍、合同义务合计 $7,438 亿（营收 2.24 倍）。估值上，浮盈污染远小于 Alphabet（核心 PE 28.8–29.6x vs GAAP 27.7x，浮盈仅占净利润 5.6%），**现价对 FY27 一致预期中位 $533 折价 7%、对 SOTP 中值 $511 折价 3%——公允价格买入伟大公司，没有安全边际，也没有明显高估**。判定：**已持有可继续持有；新建仓等 $430（一档）/ $385（二档）**。最大的非共识风险不是 AI 竞争，而是**模型层是空的 + 最大客户是关联方**：来自 OpenAI 的收入 $241 亿（7.3%）、占商业 RPO 估计 32–46%，而 OpenAI 的企业 API 份额已从 50% 跌到 27%。

## 4. 各维度分析摘要

### 商业模式（段永平）→ [01](01-商业模式分析-段永平视角.md)
1. 存量 PBP：利润率 59.9%、增量利润率 73.5%、贡献 54% 经营利润；增量 IC：收入 +30% 但成本 +44%，增量利润率仅 39%。
2. **OpenAI 依赖有一手数字**：收入 $241 亿、应收 $60 亿、持股 25%；2026-04-27 起 IP 非独家、OpenAI 可用任何云、微软停付分成。
3. Copilot 是"可数席位、不可证伪的收入"：M365 商业云 +17% vs 席位 +6% → 每席位收入约 +10%，PBP 成本 +12% 明写用于支撑 Copilot。
4. Azure +43% = 市场增速（Synergy 市场 +43%，Azure 份额持平）；FY26 四季均未披露 AI 贡献点数；FY27 重述后两条增速口径都变好看。
5. 段永平四问"利润能否变 FCF"答**否**；9 个可证伪检验点（Azure ≥44% CC、席位 ≥4,000 万且继续披露、云毛利率 <62% 证伪、FY27 FCF <$250 亿证伪…）。

### 财务与估值（巴菲特）→ [02](02-财务估值分析-巴菲特视角.md)
1. 浮盈占比小但 PE 被低估：核心 PE 29.4–29.6x 而非 27.7x。
2. 折旧 15→25 年对 FY27 影响小（公司原话 "minimal benefit"）；真正影响是新租约转经营租赁 → Capex 口径被结构性压低。
3. 现金流最弱：FCF 四年零增长；FY27 FCF 估计 $600 亿（区间 $380–820 亿）、收益率 1.6%。
4. 估值公允无边际：反向折现（r=9%/PE 25x）隐含十年核心 CAGR 9.5%——可达但不宽裕；SOTP 中值 $511、压力 $343；**买点一档 $430、二档 $385**。
5. OpenAI 循环：由"剔 OpenAI +25%"反推占 RPO 32–41%。

### 行业与竞争（芒格）→ [03](03-行业竞争分析-芒格视角.md)
1. 云市场 +43% 八年最高；Azure 跟上了市场、没有跑赢市场（增量贡献 19.5%）。
2. 微软在产业链两端有租金，**模型层是空的**：持股对象在失势，份额上升者 Anthropic 的算力主体在 AWS/Google（Azure $300 亿 vs AWS >$1,000 亿）。
3. 最大客户是关联方：OpenAI 占 Azure 约 24%、占 RPO 32–46%；AWS 拿到 Frontier 独家分销。
4. 五条"会输"路径：模型层空心化/关联方集中（高，已兑现）、Capex/营收 22.9%→34.9% 且 FCF 三年 741→670 亿（高，已兑现）、Google 垂直整合与 Copilot 被绕过（中）、监管拆捆绑（低–中）。
5. CMA 2025-07-31 认定微软许可做法损害 AWS/Google；Maia 自研芯片至今无公开外部客户（三大云中唯一）。

### 风险与管理层（李录）→ [04](04-风险管理层评估-李录视角.md)
1. OpenAI：持股 25%；日历 2025Q4 +$99.7 亿 = 重组稀释收益 $100 亿税前；条款两年内从独家退到非独占。
2. 表外承诺是准债务：合同义务 $7,438 亿；含融资租赁后净现金 −$300 亿。
3. 管理层 ★3：程序化回购（无择时）；四笔大并购只有 LinkedIn 可验证为正，Activision FY26 Xbox −7% 且 Q4 计提减值；**CEO PSA 指标 100% 收入增长、0% 回报率**，与 $1,160 亿 Capex 时代错配。
4. 监管：欧盟 Teams 未罚款（一手）；CMA SMS 调查 2027-02 裁定；FTC CID 无诉状；**IRS $289 亿 NOPA**。
5. 长期确定性 ★3：传统软件 ★5，但现价隐含增速（剔 OpenAI 核心利润十年 CAGR 11–13.5%，IRR 10%、PE 20–25 退出）要求 AI Capex 的回报——无法判断。

## 5. 投资论点：Bull vs Bear

### 🟢 看多
1. PBP 是 ★5 级收租生意：59.9% 利润率、73.5% 增量利润率、席位与许可仍在增长。
2. Azure 绝对值 $1,019 亿、+40%，与市场同速；Microsoft Cloud $2,144 亿。
3. 浮盈仅占净利润 5.6%，核心 PE 28.8–29.6x 处自身十年 36% 分位、NTM 24.2x 处 12% 分位——**以微软自己的标尺不贵**。
4. 单一股权、11/12 独立董事、Say-on-Pay 91.94%、程序化回购十年无择时失误。
5. OpenAI 独家条款退出的同时换来采购承诺与 25% 股权锁定；Anthropic $300 亿 Azure 承诺。
6. 应用层 57.9%、云层 40.6% 两层租金；Copilot 3,000 万席位是企业 AI 最大的可数装机。
7. 一致目标价 $573（+15%），FY27 中位 $533、FY28 中位 $637。

### 🔴 看空
1. 净利润五年 +84%、FCF +3%；FY27 Capex $1,750 亿 = 收入 44.7%；OCF/Capex 1.3x。
2. 未启动租赁一年 ×3.55 至 $3,291 亿；合同义务 $7,438 亿；含租赁净现金 −$300 至 −$520 亿。
3. 模型层空心化：OpenAI API 份额 50%→27%，Anthropic 12%→40% 且算力在别家；Maia 无外部客户。
4. 最大客户是关联方：OpenAI 收入 $241 亿、RPO 占比 32–46%、履约能力不可核；剔 OpenAI 后 RPO 增速 +84% → +25%。
5. Microsoft Cloud 毛利率 69%→66%→65%，IC 成本增速 44% > 收入 30%。
6. Copilot 收入不可证伪；Azure AI 贡献点数已停止披露；FY27 重述让两条增速口径都变好看。
7. CEO 绩效股 0% 挂回报率；折旧 15→25 年待落地；IRS $289 亿 NOPA。
8. CMA SMS 调查 2027-02 裁定，微软是三大云中唯一被点名许可做法损害竞争的。

## 8. 总结

同一套流程、同一个模型，Alphabet 和 Microsoft 给出了两种不同形状的结论。Alphabet 是"生意变好、价格变得更快"——核心 PE 90 分位，安全边际不存在；Microsoft 是"价格公允、回报路径看不清"——核心 PE 36% 分位，没有边际也没有高估。两家共享同一个结构性问题：**都在用有租金的那一层（分发/应用）的现金流，去买没有租金的模型层和租金归 Nvidia 的算力层；都有一个既是最大客户又是被投企业的关联方**（Alphabet–Anthropic、Microsoft–OpenAI），关联收入占比都不完全披露。

微软独有的是三件事：模型层伙伴正在失势（OpenAI API 份额 50%→27%）、Azure 只是跟上市场没有跑赢（增量贡献 19.5%）、CEO 的激励里没有一项回报率指标。这三件事不影响今天的利润，影响的是 $1,750 亿 Capex 和 $7,438 亿合同义务最终能换回什么。

> 巴菲特："以公允价格买入一家伟大的公司，远胜以便宜价格买入一家平庸的公司。"——微软符合前半句；本报告的全部工作，是确认"公允"这两个字，并说清为什么不能再多给。
