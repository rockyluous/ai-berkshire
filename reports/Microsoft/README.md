# Microsoft（MSFT）研究框架概览

> 基准日 2026-09-15　｜　股价 $497.12　｜　市值 $3.69 万亿　｜　财年止 6 月　｜　方法：/investment-team 四大师并行 + 共享底稿 + 四道机器复核（Fable 5.1）

## 核心结论

**公允价格买入伟大公司——没有安全边际，也没有明显高估。** 核心 PE 28.8–29.6x（浮盈仅占净利润 5.6%），处自身十年 36% 分位、NTM 24.2x 处 12% 分位；现价对 FY27 一致预期中位 $533 折价 7%。**已持有可持有；新建仓等 $430 / $385。**

最大的非共识风险不是 AI 竞争，而是**模型层是空的 + 最大客户是关联方**：来自 OpenAI 的收入 $241 亿（7.3%，10-K Note 1）、占商业 RPO 估计 32–46%，而 OpenAI 企业 API 份额已从 50% 跌到 27%；净利润五年 +84%、FCF +3%；未启动租赁一年 ×3.55 至 $3,291 亿。

巴菲特十项 checklist：**通过 2 · 部分 6 · 不通过 2**。

## 本轮非共识发现

1. FY25 10-K 的"API exclusive to Azure + ROFR"在 FY26 10-K 已删除；2026-04-27 起 IP 非独家、OpenAI 可用任何云、微软停付分成。
2. Azure +43% = 市场增速，份额五季持平 20–21%，增量贡献 19.5% 低于 AWS 与 GCP——跟上了市场，没有跑赢。
3. CEO 绩效股指标 100% 挂收入增长、0% 挂回报率（DEF 14A），与 $1,160 亿 Capex 时代错配。
4. 折旧年限 15→25 年尚未进入任何 SEC 文件，只在电话会。
5. IRS $289 亿 NOPA（10-K）——此前底稿与公开分析均未收录。

## 关键检验点

- **Q1 FY27 财报（约 2026-10-28）**：新口径 Azure 是否 ≥44%、折旧变更是否落地及量化、Copilot 席位是否继续披露、FY27 FCF 指引
- 2027-02：CMA 对微软企业软件生态的 SMS 裁定
- 每季：10-K/10-Q Note 1 关联方——来自 OpenAI 的收入与应收（FY27 起可逐季跟踪）
- OpenAI 履约能力（RPO 三成以上）——非上市，只能靠外部融资与流量信号
